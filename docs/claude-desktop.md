# Настройка Claude Desktop: «Финансовый помощник»

Пошагово, с нуля. В конце у вас будет отдельный проект со своим финансовым
промптом — и обычные чаты, куда этот промпт не попадает. Деньги в любом случае
идут через фаервол: он решает одинаково, из какого бы чата ни пришёл запрос.

## Чего в Claude Desktop нет

**Подагентов там нет.** `.claude/agents/*.md` — это фича Claude Code: отдельный
системный промпт, свой набор тулов, своё окно контекста. В Desktop такого нет, и
рецепты, обещающие обратное, описывают Claude Code.

Ближайшее по смыслу собирается из двух частей:

| Что нужно | Чем закрывается | Насколько жёстко |
|---|---|---|
| Свой системный промпт только в финансовых чатах | **Проект** + инструкции проекта | Полностью: применяются к чатам проекта и никуда больше |
| Агент не проведёт лишнего | **Фаервол** — правила, лимиты, подтверждения | Жёстко: решает не промпт, а сервис |

Порядок важен. Инструкция проекта — про удобство и гигиену контекста, а не про
безопасность: текст в промпте ничего не запрещает. Запрещает фаервол, и он
работает одинаково во всех чатах — что в проекте, что в случайном разговоре.

---

## Шаг 0. Поднять фаервол и MCP

```bash
git clone <адрес этого репозитория> tbank-ai-fw
cd tbank-ai-fw

cp .env.example .env              # см. комментарии внутри: где хранить сессию
docker compose up -d --build      # вебморда :8080, демон входа :8765
```

В `.env` укажите `TBANK_SESSION_DIR` — каталог, куда ляжет сессия банка. Claude
Desktop запускает MCP на хосте, и он читает `~/.local/share/tbank-mcp/session.json`,
поэтому проще всего указать именно его:

```
TBANK_SESSION_DIR=/Users/ваше-имя/.local/share/tbank-mcp
```

MCP останется на хосте — по-другому и нельзя: Claude Desktop запускает его
дочерним процессом и говорит через трубу, а держать вторую сторону трубы в
контейнере некому. Установить его нужно один раз:

```bash
cd mcp
python3.11 -m venv .venv && .venv/bin/pip install -e .
```

Откройте `http://127.0.0.1:8080/auth` и войдите: телефон → код из SMS → пароль.
Форму рисует вебморда, но введённое уходит **напрямую в демон на вашей машине**,
минуя контейнер, — пароль не проходит через фаервол и не попадает в контекст
модели. Сессия ложится в `~/.local/share/tbank-mcp/session.json` (права 0600).

Дальше везде `/абсолютный/путь/до/tbank-ai-fw` — замените на свой. Узнать его:
`pwd` в корне репозитория.

## Шаг 1. Подключить MCP

Файл конфигурации:

- macOS — `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows — `%APPDATA%\Claude\claude_desktop_config.json`

```jsonc
{
  "mcpServers": {
    "tbank": {
      "command": "/абсолютный/путь/до/tbank-ai-fw/mcp/.venv/bin/python",
      "args": ["-m", "src.server"],
      "env": {
        "PYTHONPATH": "/абсолютный/путь/до/tbank-ai-fw/mcp",
        "TBANK_FIREWALL_URL": "http://127.0.0.1:8080",
        // closed — при недоступном фаерволе не выполнять НИЧЕГО.
        // «Фаервол упал» не может означать «значит, можно всё».
        "TBANK_FIREWALL_FAILMODE": "closed",
        // По этому имени фаервол различает потребителей в журнале и в правилах.
        "TBANK_AGENT_NAME": "claude-desktop"
      }
    }
  }
}
```

Если файла нет — создайте. Если есть другие MCP-серверы — допишите этот внутрь
существующего `mcpServers`, не затирая остальное.

После правки **полностью выйдите из Claude Desktop** и запустите заново: закрыть
окно недостаточно, переменные окружения читаются при старте процесса MCP.

Подключение одно на все чаты. Ограничивает не оно, а фаервол: деньги в любом
чате пойдут через правила, лимиты и подтверждение владельца. Если когда-нибудь
понадобится развести чаты жёстче — у правил есть поле «Агент», и достаточно
завести второе подключение с другим `TBANK_AGENT_NAME`.

## Шаг 2. Проект и его инструкции

Claude Desktop → **Projects** → новый **приватный** проект «Финансовый помощник».
Инструкции проекта применяются ко всем чатам внутри него и **не попадают** в
обычные чаты — это ровно то, что нужно.

Готовый текст — [`project-instructions.md`](project-instructions.md). Скопируйте
его целиком в поле инструкций проекта.

Дальше в первом чате проекта нажмите **+** под полем ввода и включите `tbank`.
Подключения включаются на разговор, так что в чатах, где банк не нужен, его
можно просто не включать.

> Подключения доступны только в **приватных** проектах.

## Шаг 3. Скилы (необязательно)

В репозитории лежат 10 скилов — как вести перевод, как собрать корзину, как
купить билет. В Claude Code они подхватываются сами; в Desktop заливаются
вручную, по одному ZIP на скил:

```bash
cd mcp/skills
for d in tbank tbank-transfer-money tbank-bill-pay tbank-cards-documents tbank-budget-analyzer; do
    zip -qr "/tmp/$d.zip" "$d"          # папка должна лежать в корне архива
done
```

Затем **Customize → Skills → +** и загрузить архивы. Начните со скила `tbank` —
он маршрутизатор и сам отправит в нужный.

## Как проверить, что всё сошлось

1. «Покажи мои счета» — работает сразу, чтение фаервол пропускает.
2. «Переведи 10 рублей на +79991234567» — приходит ссылка на подтверждение.
   Нажимаете «Подтвердить» в вебморде, и агент продолжает **сам**, не дожидаясь
   вашего сообщения.
3. На вкладке **Журнал** видно оба запроса, с решением и причиной.

## Профиль устройства — настраивать не нужно

Описание телефона задавать не требуется: вход и платёж берут его из одного места
(`client.CAPTURED_DEVICE`). Если всё же хотите описывать свой настоящий аппарат,
есть `TBANK_DEVICE_SCREEN_WIDTH` / `_HEIGHT` (пиксели), `TBANK_DEVICE_LANGUAGE`,
`TBANK_DEVICE_TIMEZONE`, `TBANK_DEVICE_TIMEZONE_NAME`, `TBANK_DEVICE_MODEL` — они
меняют оба блоба разом, так что одним телефоном он и останется. После смены лучше
перелогиниться и не скакать профилем между попытками: для антифрода это отдельный
сигнал.

## Что это НЕ даёт

- **Разделение чатов — это гигиена контекста, а не граница.** Подключение можно
  включить в любом чате. Границу держит фаервол, одинаково везде.
- **Инструкции проекта не запрещают ничего.** Модель может их не выполнить — на
  этот случай и написан фаервол.
- Если нужен именно подагент со своим промптом и урезанным списком тулов — это
  **Claude Code**: файл `.claude/agents/финансовый-помощник.md` с полем `tools:`.
  Desktop так не умеет.
