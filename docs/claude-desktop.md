# Настройка Claude Desktop: «Финансовый помощник»

Пошагово, с нуля. В конце у вас будет отдельный проект, в котором агент умеет
работать с банком, — и обычные чаты, где он этого не умеет и где нет ни слова
финансового промпта.

## Чего в Claude Desktop нет

**Подагентов там нет.** `.claude/agents/*.md` — это фича Claude Code: отдельный
системный промпт, свой набор тулов, своё окно контекста. В Desktop такого нет, и
рецепты, обещающие обратное, описывают Claude Code.

Ближайшее по смыслу собирается из трёх частей, и каждая закрывает свою:

| Что нужно | Чем закрывается | Насколько жёстко |
|---|---|---|
| Свой системный промпт только в финансовых чатах | **Проект** + инструкции проекта | Полностью: применяются к чатам проекта и никуда больше |
| Финансовые тулы не мешаются в общих чатах | Два подключения MCP + тумблеры в чате | Дисциплина: тумблер можно включить где угодно |
| Агент не проведёт лишнего | **Фаервол** — правило по полю «Агент» | Жёстко: решает не промпт, а сервис |

Порядок важен. Инструкция проекта — про удобство, а не про безопасность: текст в
промпте ничего не запрещает. Запрещает фаервол, и именно поэтому третья строка
таблицы существует.

---

## Шаг 0. Поднять фаервол и MCP

```bash
git clone <адрес этого репозитория> tbank-ai-fw
cd tbank-ai-fw

docker compose up -d --build      # вебморда на http://127.0.0.1:8080

cd mcp
python3.11 -m venv .venv && .venv/bin/pip install -e .
./bin/tbank-authd &               # демон входа, слушает только 127.0.0.1
```

Откройте `http://127.0.0.1:8080/auth` и войдите: телефон → код из SMS → пароль.
Форму рисует вебморда, но введённое уходит **напрямую в демон на вашей машине**,
минуя контейнер, — пароль не проходит через фаервол и не попадает в контекст
модели. Сессия ложится в `~/.local/share/tbank-mcp/session.json` (права 0600).

Дальше везде `/абсолютный/путь/до/tbank-ai-fw` — замените на свой. Узнать его:
`pwd` в корне репозитория.

## Шаг 1. Два подключения MCP вместо одного

Один и тот же сервер, разные имена агента. Фаервол видит их как разных
потребителей и может судить по-разному.

Файл конфигурации:

- macOS — `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows — `%APPDATA%\Claude\claude_desktop_config.json`

```jsonc
{
  "mcpServers": {
    // Для проекта «Финансовый помощник». Деньги проходят обычным путём:
    // правила → норма без подтверждения → лимиты → подтверждение владельца.
    "tbank-финансы": {
      "command": "/абсолютный/путь/до/tbank-ai-fw/mcp/.venv/bin/python",
      "args": ["-m", "src.server"],
      "env": {
        "PYTHONPATH": "/абсолютный/путь/до/tbank-ai-fw/mcp",
        "TBANK_FIREWALL_URL": "http://127.0.0.1:8080",
        "TBANK_FIREWALL_FAILMODE": "closed",
        "TBANK_AGENT_NAME": "финансовый помощник"
      }
    },
    // Для всего остального: посмотреть баланс и траты можно, тратить — нет.
    // Ограничение живёт в фаерволе, а не в этом файле: файл агент не читает.
    "tbank-справка": {
      "command": "/абсолютный/путь/до/tbank-ai-fw/mcp/.venv/bin/python",
      "args": ["-m", "src.server"],
      "env": {
        "PYTHONPATH": "/абсолютный/путь/до/tbank-ai-fw/mcp",
        "TBANK_FIREWALL_URL": "http://127.0.0.1:8080",
        "TBANK_FIREWALL_FAILMODE": "closed",
        "TBANK_AGENT_NAME": "общий чат"
      }
    }
  }
}
```

Если файла нет — создайте. Если есть другие MCP-серверы — допишите эти два
внутрь существующего `mcpServers`, не затирая остальное.

После правки **полностью выйдите из Claude Desktop** и запустите заново: закрыть
окно недостаточно, переменные окружения читаются при старте процесса MCP.

## Шаг 2. Правило в фаерволе, которое это подпирает

Само по себе имя агента ничего не значит — значение ему придаёт правило.
Заводится в вебморде: **Правила → Новое правило**.

- Название: `Общий чат — только чтение`
- Приоритет: **5** (выше всех — разбирается раньше остальных)
- Решение: **Запретить**
- Причина: `этот чат не для денег — переключитесь в проект «Финансовый помощник»`
- Типы операций: ✅ деньги, ✅ запись
- Условие: `Агент` · `не равно` · `финансовый помощник`

Что получается: в общем чате `list_accounts` и `spending_categories` работают, а
`transfer` и `grocery_checkout` возвращают внятный отказ со ссылкой. В проекте
«Финансовый помощник» всё идёт обычным порядком — с подтверждениями и лимитами.

Имя агента задаётся переменной окружения процесса MCP, а не приходит из чата, —
подделать его из переписки нельзя.

## Шаг 3. Проект и его инструкции

Claude Desktop → **Projects** → новый **приватный** проект «Финансовый помощник».
Инструкции проекта применяются ко всем чатам внутри него и **не попадают** в
обычные чаты — это ровно то, что нужно.

Готовый текст — [`project-instructions.md`](project-instructions.md). Скопируйте
его целиком в поле инструкций проекта.

Дальше в первом чате проекта нажмите **+** под полем ввода и включите
`tbank-финансы`, а `tbank-справка` выключите. Подключения включаются на разговор,
поэтому в общих чатах оставляйте включённой только `tbank-справка`.

> Подключения доступны только в **приватных** проектах.

## Шаг 4. Скилы (необязательно)

В репозитории лежат 10 скилов — как вести перевод, как собрать корзину, как
купить билет. В Claude Code они подхватываются сами; в Desktop заливаются
вручную, по одному ZIP на скил:

```bash
cd mcp/skills
for d in tbank tbank-transfer-money tbank-bill-pay tbank-cards-documents tbank-budget-analyzer; do
    zip -qr "/tmp/$d.zip" "$d"          # папка должна лежать в корне архива
done
```

Затем **Customize → Skills → +** и загрузить архивы. Начните со скила `tbank` —
он маршрутизатор и сам отправит в нужный.

## Как проверить, что всё сошлось

1. В общем чате: «покажи мои счета» — работает. «переведи 10 рублей на
   +79991234567» — приходит отказ фаервола со ссылкой.
2. В проекте «Финансовый помощник»: тот же перевод — приходит ссылка на
   подтверждение. Нажимаете «Подтвердить» в вебморде, агент продолжает **сам**,
   не дожидаясь вашего сообщения.
3. На вкладке **Журнал** видно оба запроса, с решением и причиной.

## Профиль устройства — настраивать не нужно

Описание телефона задавать не требуется: вход и платёж берут его из одного места
(`client.CAPTURED_DEVICE`). Если всё же хотите описывать свой настоящий аппарат,
есть `TBANK_DEVICE_SCREEN_WIDTH` / `_HEIGHT` (пиксели), `TBANK_DEVICE_LANGUAGE`,
`TBANK_DEVICE_TIMEZONE`, `TBANK_DEVICE_TIMEZONE_NAME`, `TBANK_DEVICE_MODEL` — они
меняют оба блоба разом, так что одним телефоном он и останется. После смены лучше
перелогиниться и не скакать профилем между попытками: для антифрода это отдельный
сигнал.

## Что это НЕ даёт

- **Тумблер подключения можно включить в любом чате.** Разделение чатов — это
  удобство и гигиена контекста, а не граница. Границу держит фаервол, и в общем
  чате она выражена правилом из шага 2.
- **Инструкции проекта не запрещают ничего.** Модель может их не выполнить — на
  этот случай и написан фаервол.
- Если нужен именно подагент со своим промптом и урезанным списком тулов — это
  **Claude Code**: файл `.claude/agents/финансовый-помощник.md` с полем `tools:`.
  Desktop так не умеет.
